The Nature of Code OPENRNDR
========

This project is an implementation of the book **The Nature of Code** examples in OPENRNDR.

Features
--------

- [x] Randomness:
  - [x] Traditional Random Walker
  - [x] Random Number Distribution
  - [x] Gaussian Distribution
  - [x] Perlin Noise
- [x] Vectors:
  - Understanding Vectors (OPENRDNR Guide)
    - Increased the point number to 1000
    - Added screenshot functionality (sue space to capture)
  - Understanding Vectors GUI (OPENRDNR Guide)
    - A standalone application with controls
  - [x] Bouncing ball with no vectors
  - [ ] Bouncing ball with Vector2
  - [ ] Motion 101 (velocity)
  - [ ] Motion 101 (velocity and constant acceleration)
